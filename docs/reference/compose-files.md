Every setting comes from the `.env` file next to this file; `.env.example` lists them. To run your own build instead, replace each `image:` with `build: { context: ., dockerfile: apps/<app>/Dockerfile }`.

## `deploy/docker-compose.yml`

The stack for a hosting panel or an existing reverse proxy: Dokploy, Portainer, or any Traefik, Caddy or nginx that reaches containers on a Docker network. It publishes no host port. Route one public hostname to the `web` service on port 3001: the web app forwards the API paths to `server` on the internal network, so the browser sees a single origin.

Three values are required: FREENARY_URL, POSTGRES_PASSWORD and BETTER_AUTH_SECRET. Every other server setting can come from an optional `.env` file next to this file; `.env.example` at the repository root lists them. `../docker-compose.yml` is the stack that publishes host ports.

## `docker-compose.dev.yml`

The development stack: PostgreSQL, the database migrations, the API server, the web app and the documentation site, built from the working tree. Compose watch syncs every edit under apps/, packages/ and docs/ into the containers. `bun run dev:up` starts it under a project named after the worktree. No service publishes a host port: Kiri routes each hostname from its labels.

### `postgres`

- Image: `postgres:18-alpine`
- Published ports: none
- Exposed, not published: `${POSTGRES_PORT:-5432}`
- Healthcheck: `pg_isready -U ${POSTGRES_USER:-postgres} -d ${POSTGRES_DB:-freenary}`
- Volumes: `pgdata:/var/lib/postgresql`
- Environment it sets: `POSTGRES_DB`, `POSTGRES_PASSWORD`, `POSTGRES_USER`

## `docker-compose.mail.yml`

An SMTP transport for the development stack, with no mail account and no console printing: Mailpit accepts every message and holds it in a web inbox. `bun run dev:mail` layers this file over docker-compose.dev.yml. Without it the stack configures no email provider, so Freenary hides the flows that need one instead of offering them.

- Volumes: `./.docker/ai-rules.yaml:/rules/ai-rules.yaml:ro`
- Restart: `unless-stopped`

### `server`
