Send account confirmation and password-reset codes through Resend or an SMTP service.

## What changes when email is enabled

Without a delivery service, Freenary allows password and passkey sign-in but doesn't confirm addresses. It also hides `Forgot password?`.

After you configure one:

- A new user must confirm their address before signing in.
- An existing user with an unconfirmed address receives a code on their next password sign-in.
- `Forgot password?` sends a reset code.

The figures for code length, lifetime and attempts are in [Sign-in](/docs/run/sign-in). Messages contain plain English text.

## Choose where the values live

As the operator, open Settings, then **Connections**, and press `Set up`, or `Change`, on the `Email delivery` row under `Services`. Values saved there stay in the database. Only the operator sees `Services`, and the setup screen has no email step.

Environment variables are the other option. Start with `EMAIL_PROVIDER` and `EMAIL_FROM`, then add the variables for your service. Every variable is in [Email](/docs/reference/configuration#email). An environment value overrides a saved value, and the row shows `Set by your server`. See [A value in the environment wins](/docs/reference/configuration#a-value-in-the-environment-wins).

## Resend

<Steps>

<Step>

### Prepare Resend

Add your domain in the [Resend dashboard](https://resend.com) and verify its DNS records. Create a full-access API key. A sending-only key can't pass Freenary's domain-list test.

</Step>

<Step>

### Enter the credentials

Choose `Resend` and press `Continue`. Enter a `Sender address` on the verified domain, such as `Freenary <no-reply@example.com>`, and the `API key`.

In the environment, the same values are:

```dotenv
EMAIL_PROVIDER=resend
EMAIL_FROM=Freenary <no-reply@example.com>
RESEND_API_KEY=<your key>
```

</Step>

<Step>
### Apply the Resend change

Press `Save`, then `Apply now`. With environment variables, run `docker compose up -d`, or redeploy with your hosting panel. A missing value stops the start, and the server log names it.

</Step>

</Steps>

## SMTP

<Steps>

<Step>

### Enter the server details

Choose `SMTP` and press `Continue`. Enter `Sender address` and `Host`, then open `More options` for the remaining fields.

| Field | Value |
| --- | --- |
| `Port` | Empty selects `465` with `Implicit TLS`, or `587` without it |
| `Implicit TLS` | On for port `465`; off for `587`, which upgrades its connection |
| `User`, `Password` | Your SMTP login, or both empty for an unauthenticated relay |

In the environment, set these variables instead:

```dotenv
EMAIL_PROVIDER=smtp
EMAIL_FROM=Freenary <no-reply@example.com>
SMTP_HOST=smtp.example.com
```

| Variable | Value |
| --- | --- |
| `SMTP_PORT` | Unset selects `465` with `SMTP_SECURE=true`, or `587` without it |
| `SMTP_SECURE` | `true` for port `465`; `false` for `587`, which upgrades its connection |
| `SMTP_USER`, `SMTP_PASSWORD` | Your SMTP login, or both unset for an unauthenticated relay |

</Step>

<Step>

### Apply the SMTP change

Press `Save`, then `Apply now`. With environment variables, run `docker compose up -d`, or redeploy with your hosting panel.

</Step>

</Steps>

## Connection test results

`Save` tests the service before it stores the values. The test times out after 10 seconds.

| Message | Action |
| --- | --- |
| `Connection works.` | Nothing: the values are saved |
| `… refused these credentials. Check them and try again.` | Correct the key or login |
| `Unable to reach …. Check the address and your network, then try again.` | Check the host, port and outbound access |
| `A value has the wrong format. Check the fields and try again.` | Correct the invalid field |

If the service is working despite the failed test, press `Save anyway`. The values are stored without a check.

## Apply a saved change

The server reads saved values when it starts. After a save, `Services` shows `Restart to apply your changes`. Press `Apply now`: the server restarts, the section shows `Applying your settings…`, and the page reconnects on its own. If it shows `The server did not restart` instead, see [The server does not restart](/docs/run/troubleshooting#the-server-does-not-restart-after-setup).

To turn email off, choose `Off` after `Change`, press `Continue`, then `Apply now`.

## Send a real code

Create an account with an unused address. Within a minute, expect a message titled `Confirm your Freenary email address`. Check spam and your sender domain's SPF, DKIM and DMARC records when it doesn't arrive.
